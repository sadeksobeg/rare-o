# مصفوفة الوظائف — المرحلة 2

لكل شاشة من النماذج المرئية (`docs/ui/design/mockups/`): جدول (الوظيفة · موجودة فعلاً بعد فحص
الكود؟ · ناقصة؟ · تحتاج باك-إند؟ · الأولوية). **لا تخمين** — كل خانة "موجودة" مرتبطة بملف حقيقي
فحصتُه هذه الجلسة أو جلسات سابقة موثَّقة في `PROJECT_AUDIT.md`. ما لم أتحقق منه مباشرة مُعلَّم
صراحة "غير مؤكَّد — يحتاج فحصاً إضافياً" بدل افتراضه.

**ملاحظة إلزامية:** ملف `docs/ui/external/04_CLAUDE_CODE_MASTER_BRIEF.md` المُشار إليه لم يكن
موجوداً في المستودع وقت كتابة هذا الملف. لم تُفحَص أي بنود منه لأنها غير متاحة لي. إن أضفتَه
لاحقاً أراجعه في دفعة منفصلة بنفس منهج التحقق (رفض أي بند غير مؤكَّد بالكود).

رمز الأولوية: **ع** = عالية (تمنع إطلاقاً جديراً بالثقة) · **م** = متوسطة · **ل** = لاحقاً.
