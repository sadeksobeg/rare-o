# جرد الأدوات والمهارات — المرحلة 1

لا تثبيت لأي شيء في هذا المستند دون موافقة صريحة لاحقة. هذه المرحلة بحث وتوثيق فقط.

## أ. متاح فعلياً الآن (تحقَّقتُ منه، لا افتراض)

### مهارات Claude Code (Skills)
| المهارة | الصلة بالمشروع | كيف استُخدمت |
|---|---|---|
| `frontend-design` | إرشاد عام لتجنّب أنماط التصميم المولَّد الافتراضية (خلفية كريمية + طباعة كبيرة متباينة، إلخ) | استُشيرت في جلسة سابقة؛ هويتنا مقفلة أصلاً في `PLAN.md` فهي تأكيد لا مصدر قرار جديد |
| `code-review` | مراجعة دفعات التنفيذ قبل الدمج | مخصَّصة للمرحلة 3 فما بعد، لم تُستخدم بعد |
| `security-review` | مراجعة أمنية لتغييرات حساسة | غير ذات صلة بالمرحلة 1/2 (لا كود يتغيّر) |

### أدوات المتصفح والبحث
| الأداة | الاستخدام | ملاحظة |
|---|---|---|
| المتصفح المدمج (Browser pane) | فحص حقيقي للتطبيق الجاري، قياسات DOM، لقطات | استُخدم فعلياً لتشخيص وإصلاح أخطاء حقيقية في جلسات سابقة من هذا المسار |
| `WebSearch` / `WebFetch` | البحث عن مراجع رسمية والتحقق من الروابط | استُخدم لبناء `docs/ui/REFERENCES.md` — بعض الصفحات محمَّلة بجافاسكربت فلم يُجلَب متنها كاملاً (موثَّق صراحة هناك) |

### أدوات المشروع القائمة (لا تُستبدَل، القاعدة في `.mdc` صريحة)
| الأداة | الدور |
|---|---|
| Playwright + `@playwright/test` | اختبارات E2E وفحص بصري (`toHaveScreenshot` متاحة أصلاً دون تبعية جديدة) |
| `@axe-core/playwright` | فحص إمكانية الوصول الآلي — مرتبط حالياً بـ 92 فحصاً عبر `test:d1-axe` |
| Lighthouse + `chrome-launcher` | قياس الأداء/Core Web Vitals |
| ESLint 9 + `next lint` | فحص الكود الساكن |
| `tsc --noEmit` | فحص الأنواع |
| Prisma 6 | ORM وقاعدة البيانات (PostgreSQL 16) |
| `lucide-react` | الأيقونات (المعتمدة حصراً، عرض خط 1.5) |

## ب. مهارات/مكوّنات إضافية رأيتها في هذه البيئة لكنها **غير ملائمة** لهذا المشروع

| الاسم | لماذا استُبعِد |
|---|---|
| `21st-ui-build` / `21st-ui-review` وما شابه (مكتبات/مكوّنات جاهزة من كتالوج خارجي) | `PLAN.md` وقاعدة `.mdc` تمنعان صراحة أي تبعية واجهة جاهزة (`cmdk`, `sonner`, مكتبات مكوّنات) حتى مرحلة صريحة؛ القرار D15/D22 يحصران الاعتماديات الجديدة بـ `lucide-react` فقط والحوار الأصلي |
| موصل Figma (`plugin:design:figma`) | لا ملفات Figma في هذا المشروع؛ النظام نصّي (`PLAN.md` + Markdown)، لا حاجة فعلية |
| Storybook | قرار سابق صريح وموثَّق في `docs/ui/00-PHASE-0-INVENTORY.md`: "لا Storybook — المعرض الحالي `/dev` primitives" — لا أعيد فتح قرار محسوم |
