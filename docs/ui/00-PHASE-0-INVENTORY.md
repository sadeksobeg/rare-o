تاريخ: 2026-10-26

## البنية الفعلية

| البند | الواقع | قرار التكيّف |
|--------|---------|----------------|
| الإطار | Next.js 15 App Router, React 19 | يبقى |
| الأنماط | Tailwind 4 (`@import "tailwindcss"` في `app/globals.css`) لا `tailwind.config` | الرموز في `styles/tokens.css` وتُستورد من `globals.css` |
| الحركة | `components/motion` + CSS — لا Framer Motion | لا تُضاف `motion` حتى مرحلة حركة صريحة |
| الأيقونات | `lucide-react` | مطابق |
| الترجمة | `lib/i18n/dictionaries.ts` عربي/إنجليزي | لا هجرة إلى `ar.json` في موجات الواجهة |
| الخطوط | Amiri + IBM Plex Arabic (ع) · Cormorant + Source Sans 3 (إن) | Cairo + Plex أوزان 500/700 مؤجّلة لمرحلة الخطوط (تؤثر على المتجر) |
| الاختبار | `tsc`, `next lint`, Playwright, axe scripts | نفس الأوامر؛ لا Storybook — المعرض الحالي `/dev` primitives |
| الشل | عزل `useSearchParams` عبر Mount | يبقى — يمنع `undefined.call` |
