# معمارية المعلومات — RARE OUD

يعيد استخدام `docs/ui-planning/plan/03-storefront-pages.md`، `04-admin-pages.md`،
`05-trader-pages.md` (معرّفات SF/AD/TR) كمصدر أساسي، ويضيف فقط الصفحات الحقيقية الموجودة في
الكود ولم تكن مذكورة هناك (تحقَّق عبر `find app -name page.tsx`، 2026-10-28). لا تكرار لتفاصيل
كل صفحة — التفاصيل في الملفات الثلاثة أعلاه.

## زائر غير مسجَّل (المتجر العام)
لا صلاحيات تسجيل دخول. عربي أولاً، `/en/*` للإنجليزية.

| الصفحة | المسار | المعرّف |
|---|---|---|
| الرئيسية | `/` | SF-01 |
| الكتالوج | `/catalog` | SF-02 |
| المنتج | `/product/[slug]` | SF-03 |
| قائمة الطلب | `/cart` | SF-04 |
| الطلب | `/request` | SF-05 |
| العروض | `/offers`، `/offers/[slug]` | SF-06, SF-07 |
| تواصل | `/contact` | SF-08 |
| الخصوصية / الشروط / الكوكيز | `/privacy`، `/terms`، `/cookies` | SF-09 (+ إضافتان حقيقيتان غير موثَّقتين سابقاً: `/terms`, `/cookies`) |

**قاعدة ثابتة:** تاجر مسجَّل دخول يُعاد توجيهه تلقائياً من `/offers` إلى `/trader/offers`
(middleware) — لا يرى الزائر غير المسجَّل والتاجر نفس نسخة صفحة العروض.

## حدود الصلاحيات الحرجة (مفحوصة في `middleware.ts`، تحقَّق هذه الجلسة)
- جلسة تاجر على مسار إدارة ← إعادة توجيه `/forbidden?portal=admin` (وعكسه). لا تداخل جلسات.
- `/admin/*` و`/trader/*` كلاهما يتطلب `AUTH_SECRET` صالحاً (≥16 حرفاً) وإلا إعادة توجيه لتسجيل
  الدخول — لا "فشل مفتوح".
- صفحة `/dev/ui*` لا تُبنى في الإنتاج (404) — معرض مكوّنات تطويري فقط، ليس جزءاً من IA الحقيقي
  لأي دور.
