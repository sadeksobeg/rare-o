|--------|-------------------------|

## 3. وصف تفصيلي للواجهات حسب بنود التسليم

### 2.1 — محرك عرض المنتجات (Product Catalog Engine) — 140$

**المسار:** `/catalog` · الإنجليزية `/en/catalog`

#### ماذا يرى الزائر؟

1. **رأس الصفحة**  
   - عنوان رئيسي: «المجموعة»  
   - نص تعريف قصير (SEO)  
   - عدّاد النتائج («عرض X قطعة» أو ما يعادله)

2. **شريط الفئات / الفلاتر** (يتصل بـ 2.3)  
   - شرائح فئات الإطلاق: الكل · آلات موسيقية وترية · إكسسوارات  
   - على سطح المكتب: شريط لاصق تحت الهيدر  
   - على الجوال: زر يفتح ورقة فلاتر (Sheet) بارتفاع مناسب للإبهام

3. **شبكة البطاقات**  
   - كل بطاقة تعرض: صورة بنسبة تقريباً 4:5، اسم القطعة، الفئة، السعر (أو «السعر عند الطلب»)، شارة التوفر إن لزم، وشارات (جديد / مميز / تخفيض) عند وجودها  
   - عند المرور على سطح المكتب: تبديل صورة ثانوية إن وُجدت + زر إضافة سريعة لقائمة الطلب  
   - النقر على البطاقة يفتح صفحة التفاصيل

4. **عرض المزيد**  
   - زر أسفل الشبكة مع تقدّم من نوع «عرض 12 من N» عند تجاوز حجم الصفحة

5. **حالات الواجهة**

| الحالة | ما يظهر |
|--------|---------|
| تحميل | هيكل عظمي (skeleton) لشريط الفلاتر + 8 بطاقات |
| لا منتجات منشورة أصلاً | حالة فارغة: المجموعة قيد التجهيز + دعوة للتواصل |
| لا نتائج بعد الفلترة | «لا نتائج مطابقة» + مسح الفلاتر |
| منتج غير متوفر | يظهر في الشبكة بشارة عدم التوفر دون إضافة |

#### القيمة المسلَّمة للعميل
كتالوج حي يفرز الآلات والإكسسوارات، قابل للتصفح بالعربية والإنجليزية، جاهز للعرض أمام الزائر بدون لوحة إدارة أثناء الجولة.

### 2.2 — صفحات تفاصيل المنتج (Product Detail Pages) — 140$

**المسار:** `/product/[slug]` مثال: `/product/oud-classic-21`

#### تخطيط سطح المكتب

```
[ فتات الخبز: الرئيسية › المجموعة › اسم القطعة ]

┌─────────────────────────┬──────────────────────────┐
│  المعرض (صور / فيديو)   │  معلومات لاصقة:          │
│  · صورة رئيسية كبيرة    │  · الفئة                 │
│  · مصغّرات للاختيار     │  · العنوان               │
│  · تكبير /Lightbox      │  · السعر                 │
│                         │  · وصف قصير              │
│                         │  · مواصفات مختصرة        │
│                         │  · [أضف إلى قائمة الطلب] │
│                         │  · شرح مسار الطلب        │
└─────────────────────────┴──────────────────────────┘
  وصف تحريري أوسع
  جدول المواصفات الكامل
  قطع ذات صلة (حتى 4 بطاقات)
```

#### تخطيط الجوال
- المعرض بعرض الشاشة مع سحب (swipe) بين الصور  
- المعلومات أسفل المعرض  
- **شريط لاصق سفلي:** السعر + زر الإضافة (مع مراعاة المنطقة الآمنة للشاشة)

#### سلوك المعرض
- صورة واحدة أو أكثر مع مصغّرات  
- فتح Lightbox بملء الشاشة مع السابق/التالي وإغلاق  
- إن لم توجد صور: لوحة مادّية (Material Plate) بدل فراغ أبيض  
- إن وُجد وسيط من نوع فيديو في البيانات: يُعرض مشغّل فيديو داخل المعرض

#### حالات خاصة
| الحالة | الواجهة |
|--------|---------|
| متوفر | زر «أضف إلى قائمة الطلب» فعّال؛ بعد الإضافة تأكيد بصري + تحديث شارة الهيدر |
| غير متوفر (مثال: `cello-studio`) | شارة «غير متوفر حالياً» + تعطيل الإضافة + مسار بديل للتواصل |
| بدون سعر رقمي | نص «السعر عند الطلب» بدون رمز عملة مضلّل |

#### ملاحظة تسليم صادقة (مهمة للعميل)
- **الصور والمواصفات:** تعمل على المنتجات المنشورة حالياً.  
- **الفيديو:** الواجهة جاهزة لعرضه، لكن **بيانات العرض التجريبية لا تتضمن ملف فيديو لمنتج** حتى الآن. عند رفع فيديو صالح للمنتج سيظهر في المعرض دون إعادة بناء الصفحة.

### 2.3 — البحث والفلترة (Search & Filters) — 90$

**يعمل داخل:** صفحة المجموعة `/catalog` عبر معاملات الرابط (قابلة للمشاركة والإشارة المرجعية).

#### عناصر التحكم الظاهرة

| التحكم | السلوك في الواجهة |
|--------|-------------------|
| **فئة / نوع** | شرائح أو قائمة: كل المنتجات / آلات وترية / إكسسوارات |
| **السعر من – إلى** | حقلا حد أدنى وأقصى؛ تُحدَّث الشبكة فوراً عبر الرابط |
| **البحث النصي** | حقل يبحث في الاسم/الوصف؛ مثال: `عود` أو `oud` |
| **الترتيب** | الأحدث · السعر تصاعدي · السعر تنازلي |
| **مسح الفلاتر** | يعيد العرض الكامل بنقرة واحدة |

#### أمثلة روابط للمراجعة
- آلات فقط ضمن نطاق سعري:  
  `/catalog?type=string-instruments&min=2000&max=4000&sort=price-asc`
- بحث: `/catalog?q=oud` أو `/en/catalog?q=oud`
- لا نتائج: `/catalog?q=zzzz-no-match` → شاشة «لا نتائج»

#### الجوال
ورقة فلاتر منفصلة بأزرار لمس بارتفاع مناسب (~44px) بدل حشر كل الحقول في شريط ضيق.

#### توضيح نطاق
الفلترة حسب **النوع والسعر والبحث** — **لا يوجد فلتر حسب التاجر** (قرار نطاق متعمّد: التجّار لا يملكون المنتجات في نموذج الإطلاق).

### 2.4 — قائمة الطلب / السلة (Shopping Cart) — 110$

**المسار:** `/cart` · `/en/cart`  
**التسمية في الواجهة:** «قائمة الطلب» / Request list (وليست سلة دفع).

#### ماذا يرى الزائر عند وجود قطع؟

**سطح المكتب**
- عمود أيمن/أيسر (حسب اللغة): أسطر الطلب  
  كل سطر = صورة مصغّرة + الاسم + سعر الوحدة + **مفتاح كمية (− / +)** + إجمالي السطر + حذف  
- عمود ملخص لاصق: قائمة مختصرة للكميات + إجمالي القطع + الإجمالي المالي عند وحدة عملة واحدة + زر **متابعة** إلى `/request`  
- أسفل الصفحة: شرح مختصر لخطوات التسليم عبر واتساب

**الجوال**
- الأسطر أولاً ثم الشرح  
- شريط سفلي لاصق للمتابعة

#### حالات الواجهة
| الحالة | الوصف |
|--------|--------|
| فارغة | رسالة ودّية + زر «استكشف المجموعة» |
| تحميل أولي | انتظار مزامنة القائمة من التخزين المحلي للمتصفح |
| بعد إضافة من الكتالوج أو صفحة المنتج | الشارة في الهيدر تزداد مع نبضة بصرية قصيرة |
| بقاء القائمة بعد إعادة التحميل | نعم — تُحفظ محلياً في المتصفح (`localStorage`) |

#### توضيح تجاري للعميل
هذه **قائمة تجهيز طلب تواصل**، ليست سلة تُخصم منها بطاقة بنكية. الوظائف كاملة ضمن هذا النموذج: إضافة، كمية، حذف، استمرار، واستمرارية الجلسة.

### 2.5 — مسار إتمام الطلب (Request Finalization → WhatsApp) — 140$

**المسار:** `/request` · `/en/request`  
يبدأ من زر «متابعة» في قائمة الطلب.

#### الخطوة 1 — مراجعة القائمة
- ملخص للقراءة فقط (على سطح المكتب بجانب النموذج؛ على الجوال ملخص قابل للطي يظهر العدد)  
- رابط للعودة وتعديل القائمة

#### الخطوة 2 — نموذج التواصل
حقول واضحة مع تسميات ومساعدات:

| الحقل | الواجهة |
|-------|---------|
| الاسم | إلزامي |
| الهاتف | إلزامي · مثال رمز الدولة · نص مساعد «مع رمز الدولة» |
| الدولة / ملاحظة الشحن | حسب النموذج المعتمد |
| ملاحظات | اختياري |
| الموافقة | سطر تحت الزر يربط بسياسة الخصوصية |

زر الإرسال بعرض كامل على الجوال؛ حالة «جاري الإرسال…» تمنع الضغط المزدوج.

#### الخطوة 3 — نجاح التسليم (Handoff Success)
بعد نجاح الإرسال تُستبدل الصفحة بشاشة نجاح تتضمن:
- عنوان تهنئة / تأكيد  
- **الرقم المرجعي** للطلب (قابل للنسخ)  
- معاينة نص رسالة واتساب  
- زر أساسي **فتح واتساب** برابط `wa.me` مُعبَّأ مسبقاً  
- إرشادات الخطوة التالية إن فشل فتح النافذة (نسخ الرسالة / الرقم)

في لوحة الإدارة يظهر الطلب بحالة جاهزية للتسليم اليدوي (`ready_for_handoff`) ضمن مسار التجزئة.

#### ما ليس ضمن هذا البند
- لا بوابة دفع، لا بطاقة، لا الدفع عند الاستلام داخل الموقع  
- لا معالج شراء متعدد الصفحات بأسلوب متاجر الدفع العالمية  
- المقصود التعاقدي العملي: **مراجعة القائمة → تأكيد البيانات → تجهيز محادثة واتساب**

## 4. رحلة الزائر الكاملة (سيناريو تسليم مقترح — 10 دقائق)

1. فتح `/catalog` — رؤية الشبكة والفئات.  
2. اختيار فئة الآلات الوترية.  
3. ضبط نطاق سعر وترتيب.  
4. بحث بكلمة «عود».  
5. فتح منتج مثل `oud-classic-21` — معرض + مواصفات + إضافة.  
6. فتح منتج غير متوفر — التأكد من تعطيل الإضافة.  
7. فتح قائمة الطلب — تغيير الكمية.  
8. المتابعة إلى `/request` — تعبئة النموذج.  
9. الإرسال — شاشة النجاح وفتح واتساب.  
10. تغيير العرض أو اللغة — التأكد من المرآة والاستجابة.

تفاصيل إضافية: `docs/client-report/DEMO-SCRIPT.md`.

## 6. تحفظات يجب إبلاغ العميل بها بوضوح

1. **التصوير:** جزء من المنتجات التجريبية يستخدم صوراً تحريرية مشتركة وليست تصويراً فردياً لكل قطعة.  
2. **فيديو المنتج:** مدعوم في الواجهة؛ غير متوفر في بيانات العرض الحالية.  
3. **لا دفع إلكتروني** في هذا القسم — النهاية واتساب.  
4. **تسمية السلة:** في الواجهة «قائمة الطلب» لتطابق نموذج العمل.  
5. **سياسة الخصوصية:** قد تحتوي نصاً مؤقتاً حتى يزوّد العميل النص النهائي.  
6. **واتساب الإنتاجي (QR / رقم حي على الخادم):** خطوة تشغيل منفصلة عن واجهة المتجر نفسها.
