## 2. وصف الواجهات والسلوك

### 4.1 — تحويل الطلب إلى واتساب (مؤجّل الربط الحي)

**ما هو مُسلَّم الآن:**
- من سلة المتجر → طلب تجزئة (`RetailRequest`) بحالة `ready_for_handoff`.
- توليد رسالة واتساب ثنائية اللغة (عربي/إنجليزي) + رابط `wa.me` مسبق التعبئة.
- فتح الرابط من المتجر أو من الإدارة يسجّل حدث «فتح التحويل» ويُحدّث الحالة عند الاقتضاء.
- إعادة توليد الرسالة/الرابط من الإدارة دون إنشاء طلب مكرر.

**ما هو مؤجّل صراحة:**
- الربط التلقائي الحي لمحتوى السلة بمحادثة واتساب مفتوحة عبر Baileys/QR.
- إرسال تلقائي عبر WhatsApp Business API.
- إشعارات حالة الطلب للعميل عبر واتساب (ملغاة من النطاق أصلاً).

يمكن لاحقاً ربط محادثة يدوياً من صندوق الوارد (`/admin/inbox`) عند تفعيل الربط الحي.

### 4.2 — نظام إدارة الطلبات

- قائمة الإدارة `/admin/requests`: تصفية بالحالة، بحث (مرجع / اسم / هاتف)، ترقيم صفحات، عمود آخر حدث.
- تفاصيل `/admin/requests/[id]`: بيانات العميل، **ملاحظات العميل**، الوجهة، الشحن، البنود، رسالة التحويل المحفوظة، الحمولة المهيكلة.
- قسم «محادثة واتساب المرتبطة» — يظهر الرابط إن وُجدت محادثة مربوطة يدوياً؛ وإلا رسالة توضيح أن الربط الحي مؤجّل.
- دورة حياة من الاستلام حتى الإغلاق عبر انتقالات مسموحة فقط (انظر 4.3).

### 4.3 — تحديثات الحالة داخل المنصة

حالات الطلب:

| الحالة | المعنى التشغيلي |
|--------|-----------------|
| `draft` | مسودة |
| `ready_for_handoff` | جاهز للتحويل |
| `handoff_opened` | فُتح التحويل |
| `in_follow_up` | متابعة |
| `completed` | مكتمل |
| `cancelled` | ملغى |

- شريط تقدّم الحالة + شريحة حالة في صفحة التفاصيل.
- انتقالات إدارية مضبوطة خادمياً مع ملاحظة اختيارية.
- سجل أحداث تدقيقي (`RetailHandoffEvent`): تحضير / فتح / إعادة توليد / تغيير حالة.
- ظهور الأحداث في موجز نشاط لوحة الإدارة + طابور الإجراءات للطلبات التي تنتظر الإدارة.
- بعد كل انتقال: تحديث فوري للقائمة والتفاصيل والرئيسية (`revalidatePath`).

**ملاحظة نطاق:** «فوري» = داخل لوحة الإدارة بعد الإجراء — وليس بثاً لحظياً للعميل عبر واتساب/بريد.

## 3. مسارات تجريبية سريعة

1. متجر → أضف منتجات → أكمل طلب التجزئة → افتح رابط واتساب (رسالة ثنائية اللغة حسب لغة الجلسة).  
2. إدارة → `/admin/requests` → صفِّ / ابحث → افتح طلباً.  
3. تفاصيل → تحقق من ملاحظات العميل والبنود وسجل الأحداث.  
4. عمليات → انقل الحالة (مثلاً متابعة → مكتمل) → تحقق من الشريط والسجل وطابور الرئيسية.  
5. (اختياري لاحقاً) صندوق الوارد → ربط يدوي لمحادثة بطلب تجزئة → يظهر رابط «فتح في الصندوق» في تفاصيل الطلب.

## 4. ملاحظات صريحة للعميل

1. **لا دفع إلكتروني** في هذا القسم — الطلب تحويل للمتابعة اليدوية.  
2. **ربط واتساب الحي (4.1 الكامل) مؤجّل** بقراركم؛ التحويل عبر `wa.me` يعمل الآن.  
3. إشعارات حالة الطلب للعميل عبر واتساب **خارج النطاق**.  
4. طلبات التجزئة ملك الإدارة؛ بوابة التاجر تغطي الصفقات والجملة فقط.
