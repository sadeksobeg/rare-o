# دليل المشرف — RARE OUD

دليل مختصر للفريق الإداري بعد الإطلاق.

## الدخول

- المسار: `/admin/login`
- الحسابات تُنشأ من البذرة الأولى أو يدوياً في قاعدة البيانات — لا تسجيل ذاتي عام.

## لوحة التحكم

- **الرئيسية:** مؤشرات KPI، قائمة إجراءات، آخر النشاط.
- **الطلبات:** `/admin/requests` — متابعة حالة طلبات التجزئة وربطها بواتساب.
- **المنتجات:** `/admin/products` — نشر/أرشفة، أسعار، وسائط (حتى 8 ملفات).
- **التجّار:** `/admin/traders` — إنشاء حسابات وتعطيلها.
- **الصفقات:** `/admin/deals` — قبول/رفض مع سبب؛ تحذير تعارض فقط (لا منع تلقائي).
- **الجملة:** `/admin/wholesale` — تتبع الشحن والناقل.
- **العملاء:** `/admin/customers` — سجل التواصل وروابط المحادثات.
- **صندوق الوارد:** `/admin/inbox` — محادثات واتساب الموحّدة (يتطلب ربط هاتف حي).

## منتجات وكتالوج

1. أنشئ أو حرّر المنتج (عربي/إنجليزي، مواصفات، توفر).
2. ارفع الصور/فيديو mp4/webm عند الحاجة.
3. غيّر الحالة إلى **منشور** للظهور في `/catalog`.
4. للاستيراد الجماعي: `docs/templates/catalog-import.csv` و `npm run catalog:import`.

## واتساب

- الربط من واجهة صندوق الوارد (QR).
- لا تشارك مجلد `.wa-auth` — يُعتبر سراً.
- إعادة الربط: راجع `RUNBOOKS/whatsapp-relink.md`.

## قبل الإنتاج

- عطّل `RO_SHOW_UI_FIXTURES`.
- نفّذ `npm run purge:demo -- --apply` على staging بعد نسخ احتياطي إن لزم.
- راجع `GO-LIVE-CHECKLIST.md`.
