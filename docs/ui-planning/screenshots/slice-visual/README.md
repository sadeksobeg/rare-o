# Slice visual — هوية الخلفية + أزرار + انتقالات

## النطاق المنفَّذ
- **BrandWallpaper** (cream فقط): ختم العلامة الحقيقي + نغمات/ريشة مملوءة — متجر + غلاف تاجر. **بدون** ورق حائط على الهيرو أو الشاشات الداكنة.
- **أزرار مشتركة**: تباين أعلى، ظل/لمعان، ripple افتراضي على `primary` / `inverse-primary`، احترام `prefers-reduced-motion`.
- **حركة**: `Reveal` / `ro-reveal-up`، رفع بطاقة خفيف + تكبير صورة، صقل Dialog/Sheet، `overflow-x-clip` على غلاف المتجر/التاجر والهيرو.
