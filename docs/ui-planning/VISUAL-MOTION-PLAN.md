## الجزء 1 — الموقف والقواعد

### 1.1 المبدأ

الموقع العالمي ليس الأكثر حركة، بل الأدق. حركة لها وظيفة وتحمل هوية العلامة: صدى الصوت، وأوتار العود، ووردته. أي حركة لا تؤدي إحدى هذه الوظائف الخمس تُحذف:

| الوظيفة | مثال |
|---|---|
| توجيه | مؤشر التبويب ينزلق، شريط التقدم |
| تأكيد | الصورة تطير إلى القائمة، علامة صح ترسم نفسها |
| ربط | بطاقة تتحول إلى صفحة القطعة |
| حالة | اتصال واتساب، رسالة تصل، تحميل |
| هوية | الحلقات، الأوتار، خطوط الخشب |

### 1.2 المحظورات (باقية)

ارتداد مبالغ (overshoot > 3%)، emoji، زجاجية، توهج نيون، سرقة التمرير، فيديو أو صوت يعمل تلقائياً، عدّادات ضغط وهمية.

### 1.3 مستويات الحركة

| المستوى | أين | سقف الحركة |
|---|---|---|
| **A** | المتجر العام | غنية: تتابع، تحويلات، تفاعل المؤشر |
| **B** | بوابة التاجر | رشيقة: دخول عناصر، انتقال معالج، إشعارات |
| **C** | الإدارة | وظيفية: ≤ 200ms، تأكيدات وتحديثات حية |
| **Lite** | كل مكان عند: تقليل الحركة، Save-Data، جهاز ضعيف (ذاكرة ≤ 4GB أو أنوية ≤ 4) | انتقالات opacity قصيرة فقط |

## الجزء 3 — نظام الحركة

### 3.1 الرموز (إضافة إلى المعتمد)

```css
:root {
  /* المعتمد: instant 90 · fast 160 · base 240 · slow 420 · enter 700 · hero 1100 */
  --ro-dur-stagger: 70ms;
  --ro-dur-ripple: 600ms;
  --ro-ease-settle: linear(0, 0.55, 0.9, 1.02, 1); /* تجاوز ≤ 2% */
  --ro-ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1);
}
@media (prefers-reduced-motion: reduce) {
  :root {
    --ro-dur-fast: 1ms;
    --ro-dur-base: 1ms;
    --ro-dur-slow: 1ms;
    --ro-dur-enter: 1ms;
    --ro-dur-hero: 1ms;
  }
}
```

### 3.2 المكتبة — `components/motion/`

Reveal / Stagger · PressRipple · StringLine · DrawIn · TiltSurface · FlyToTarget · CountUp · AnimatedIcon (V2) · SharedImage (V3) · MotionProvider · useScrollSpy.

كل مكوّن له فرع Lite. الحركات المحيطة تتوقف بعد 5 ثوانٍ (WCAG 2.2.2).

### 3.3 أنماط CSS أولاً

`@starting-style` للحوارات · `grid-template-rows: 0fr → 1fr` للطي · مؤشر تبويب `transform` · `animation-timeline: scroll()` / `view()` مع بديل · صور من blurDataURL · شارات 160ms · طي أسطر القائمة · تتابع معالج RTL.

### 3.4 قواعد صارمة

1. تحريك `transform` و`opacity` فقط (`clip-path` بحدود).
2. عنصر LCP لا يُحرَّك قبل الرسم الأول.
3. لا أكثر من 12 عنصراً يتحرك في آن.
4. `will-change` أثناء الحركة فقط.
5. الحلقات المحيطة تتوقف بعد 5 ثوانٍ وتستأنف عند التفاعل.
6. كل حركة لها بديل Lite؛ كل معلومة تُعرض بلا حركة أيضاً.

## الجزء 4 — نظام الأيقونات (V2)

1. واجهة عامة: lucide-react، خط 1.5، أحجام 16/20/24.  
2. آلات وفئات: مجموعة مخصّصة مؤقتة قابلة للاستبدال.  
3. رسوم خطية 96–160px للفارغ والخطأ.  
4. ستة رموز علامة: الوردة، الخشب، الملاوي، الوتر، اليدوي، الصدى.

لا حروف مفردة، لا emoji، لا كرتون. زخرفية: `aria-hidden`. وحدها: `aria-label` من القاموس. الأسهم تنعكس في RTL.
