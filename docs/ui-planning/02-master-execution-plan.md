## 1. الملخص التنفيذي (للإدارة والعميل)

ننفّذ إعادة بناء واجهات منصة RARE OUD وفق خطة مقفلة واحدة، باتجاه **«فخامة هادئة تقودها الحرفة»**، دون لمس منطق الأعمال المعتمد (لا دفع، ثلاث مسارات منفصلة، واتساب Baileys، التجّار بلا ملكية منتجات).

| الطبقة | ماذا يحصل |
|--------|-----------|
| المتجر العام | Hero رنيني، كتالوج بصور حقيقية أو Material Plate، قائمة طلب (ليست سلة دفع)، تسليم واتساب واضح |
| الإدارة | شريط جانبي هادئ، لوحة KPI بلا رسوم، صندوق وارد متجاوب، إدارة الكتالوج والطلبات والصفقات والجملة |
| بوابة التاجر | أعلى استثمار تصميمي للفرد، هاتف أولاً، معالجات للصفقات والجملة، تعريب كامل |
| النظام | توكنات، خطوط Amiri/Plex، lucide فقط كمكتبة جديدة، WCAG 2.2 AA، SEO، أداء على 4G بطيء |

**المدة التقديرية (مراجع واحد):** نحو **23–31 يوم عمل** عبر P0→P8 حسب الملف 07.  
**بوابات التوقف:** بعد كل مرحلة / شريحة — لا انتقال دون موافقتك.

## 3. المبادئ الحاكمة (لا تُكسر)

1. العربية أولاً لكل الأدوار؛ الإنجليزية ثانوية كاملة.  
2. لا اختراع حقول/حالات/أسعار/MOQ/شحن.  
3. لا مكتبات UI ثقيلة ولا رسوم بيانية؛ `lucide-react` فقط.  
4. كل نص من القاموس؛ كل لون/مسافة من التوكنات؛ خصائص CSS منطقية فقط.  
5. التاجر أهم استثمار UX رغم قلة العدد.  
6. صور الكتالوج/PDP قبل أي polish إضافي على الـ Hero (بعد P1–P2).  
7. لا تعديل على ملفات الخطة 00–07؛ التعارضات تُحل عبر D27+ بعد موافقتك.
